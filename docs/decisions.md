# Accepted decisions

These entries index accepted choices, not newly executed hosted operations. Recorded 2026-10-26 from repository evidence.

- **D01 — Shared source and three outputs.** Astro shell/shared Svelte views preserve website/offline/connected parity. Development dependencies are allowed; downloadable HTML embeds required assets. Supersedes single handwritten active-HTML guidance. Evidence: [README](../README.md), [builder](../scripts/build-offline.mjs), [package](../package.json).
- **D02 — Track-first authoring.** Automatic sections, optional ends and real gaps replace manual Add section/explicit Save instructions. Rationale: prepare the whole party through tracks while retaining legacy import meaning. Evidence: [requirements](track-first-requirements.md), [v2 documents](../src/lib/documents.ts), [plan history](../plan.md).
- **D03 — Timing uncertainty survives.** Preserve source events/UUIDs, inherited twelve-hour rollover, unknown final boundaries and original text. Estimated placement cannot become exact time. Explicit source-clock alignment precedes mixing Now tracks. Evidence: [parser](../src/lib/parser.ts), [track-first tests](../tests/track-first.test.ts).
- **D04 — Managed password auth.** Current confirmation-off Supabase setup supersedes historical mail-code/SMTP activation guidance for this selected release. Email ownership remains unverified; admin/manual recovery is documented separately. No privileged credential in the browser. Evidence: [setup](supabase-setup.md), E15 in [backlog](../backlog.md). Public-release verification/recovery policies remain pending.
- **D05 — Autosave and LocalStorage recovery.** Revisioned acknowledged saves, account-scoped complete snapshots/outbox and conflict copies replace explicit-save-only behavior. Storage failure is session-only; no encrypted/guaranteed durable cache claim. IndexedDB is deferred. Evidence: [sync](../src/lib/plan-sync.ts), [verification](verification.md).
- **D06 — Polling fallback.** Fifteen-second/on-focus refresh works without Realtime publication. Private push/convergence remains E13-S2; no two-second guarantee. Evidence: [cloud workspace](../src/views/CloudPlanWorkspace.svelte).
- **D07 — Sticky ruler and Top.** Selectable intervals and large alternatives replace annotation lanes; boundary labels and pinned Full scale coexist with scroll-follow. Later Top restoration supersedes M11's remove-Top proposal. Evidence: E22-S5 in [backlog](../backlog.md), [PartyPage](../src/views/PartyPage.svelte).
- **D08 — Local engineering workflow.** Fixed command wrappers provide bounded, payload-free lifecycle evidence; no runtime hooks/global settings or shipped telemetry. `.agents/skills` packages follow [official repository discovery guidance](https://learn.chatgpt.com/docs/build-skills), fetched 2026-10-26. Package inspection/manual execution is distinct from host catalog discovery. See [integrations](integrations.md) and [gate rules](workflow-gates.md).
- **D09 — Evidence-qualified completion.** Self-review is labeled self-review. Local synthetic checks cannot close hosted/native gates. An unavailable runtime capability is recorded with a supported alternative; it cannot be silently claimed verified. Evidence: [adoption backlog](agentic-adoption-backlog.md), [pilot](tasks/pilot-doc-links.md).
- **D10 — Continuous numbered chapters (2026-10-26).** User requested numbering, continued scrolling into the next chapter and category counts. Section selection now jumps within the complete list; user scroll follows chapters without changing filters or saving. Numbers represent current plan order and survive filters; badge/menu counts represent the complete current plan. Collapsed genre alternatives preserve large controls with visible timing evidence. Supersedes older no-numbering and selected-section-only rendering guidance. Evidence: [UI task](tasks/ui-ux-fixes.md), [tracks](../src/views/TracksPage.svelte), [browser regression](../tests/browser/planner.spec.ts).
